# Contributing

```bash
pnpm install
pnpm check
pnpm pack:check
```

Requirements:

- Preserve Cordis reactive `inject` and reversible effect ownership.
- Keep platform packages independent of Codex/PingClaw SDKs.
- Never log credentials, cookies, confirmation tokens, or private post text.
- Add lifecycle tests for every provider and adapter.
- Do not add CAPTCHA bypass, credential submission, or bulk engagement.
- Update English and Chinese documentation for public behavior.
